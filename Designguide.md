STORYBOOK CITY
==============

Environment Art Direction Guide v1.0
------------------------------------

### Project Vision

Create a warm, handcrafted, storybook-inspired city that feels like a collection of unique characters living in the same world.

The city should combine:

*   The modularity and production efficiency of city-building games
    
*   The charm and storytelling of handcrafted miniature dioramas
    
*   The readability of stylized game environments
    
*   The emotional warmth of collectible display pieces
    

The goal is not to create a city of beautiful buildings.

The goal is to create a city of memorable characters disguised as buildings.

Core Design Philosophy
======================

Every building must answer three questions:

1.  What is it?
    
2.  What does it do?
    
3.  What personality does it have?
    

A player should recognize a building before reading any sign.

If all text is removed from the city, the building should remain identifiable.

Reference Analysis
==================

Reference A — Storybook Book Café
---------------------------------

Strengths:

*   Emotional
    
*   Rich storytelling
    
*   Handcrafted charm
    
*   Premium appearance
    
*   Strong atmosphere
    

Weaknesses:

*   Too detailed for mass production
    
*   Every building becomes a landmark
    
*   Difficult to scale to an entire city
    
*   Buildings become visually repetitive when multiplied
    

Reference B — Modular Café
--------------------------

Strengths:

*   Clean footprint
    
*   Reusable geometry
    
*   Production friendly
    
*   Easy city planning
    
*   Easy asset reuse
    

Weaknesses:

*   Generic
    
*   Lacks personality
    
*   Weak storytelling
    
*   Function unclear without signage
    

Final Direction
===============

Use Reference B as the structural foundation.

Use Reference A as the storytelling layer.

The city should feel handcrafted without becoming overdesigned.

Building Formula
================

Every building is created using:

80% Structure20% Identity

Structure Layer (80%)
---------------------

All buildings should begin from a modular architectural foundation.

Requirements:

*   Simple footprint
    
*   Clear geometry
    
*   Efficient proportions
    
*   Reusable construction logic
    
*   Grid-friendly placement
    
*   Easy asset variation
    

Example:

Simple boxSimple roofSimple entranceSimple facade

This foundation should be shared across most buildings.

Identity Layer (20%)
--------------------

Each building receives a unique architectural signature.

Identity should come from:

*   Silhouette
    
*   Roofline
    
*   Hero architectural element
    
*   Window language
    
*   Props
    
*   Storytelling details
    

Identity should NOT come primarily from color.

Recognition System
==================

Recognition occurs in three layers.

Layer 1 — Silhouette
--------------------

Visible from long distance.

The silhouette should communicate function.

Examples:

Library:Open book roofScholar tower

Bakery:Brick chimneyRounded roof forms

Florist:Greenhouse profileFlower arch

Clockmaker:Clock towerGear crown

Toy Shop:TurretsBalloonsPlayful roofline

Layer 2 — Architecture
----------------------

Visible from medium distance.

Examples:

*   Window style
    
*   Balcony type
    
*   Door design
    
*   Facade language
    

Layer 3 — Props
---------------

Visible from close distance.

Examples:

*   Bread baskets
    
*   Book carts
    
*   Flower pots
    
*   Gear displays
    
*   Toy displays
    

Props reinforce identity.

Props do not create identity.

Silhouette Rule
===============

The silhouette is the most important design element.

Priority:

1.  Silhouette
    
2.  Architecture
    
3.  Props
    
4.  Materials
    
5.  Color
    
6.  Signage
    

If a building only works because of its sign, it has failed.

Hero Element System
===================

Every commercial or landmark building receives one signature feature.

Examples:

Library:Giant open book

Bakery:Oversized chimney oven

Florist:Living flower arch

Clockmaker:Large exterior clock

Tailor:Needle spire

Toy Shop:Balloon tower

Only one hero element per building.

Avoid stacking multiple focal points.

Materials
=========

Shared city materials create cohesion.

Primary:

*   Painted wood
    
*   Stone
    
*   Brick
    
*   Ceramic
    

Secondary:

*   Brass
    
*   Copper
    
*   Iron
    
*   Glass
    

Accent:

*   Fabric
    
*   Vegetation
    
*   Rope
    
*   Leather
    

Materials should feel handcrafted.

Avoid modern plastics.

Color Strategy
==============

Color supports identity.

Color does not create identity.

Bad Example:

Green = FloristBlue = LibraryBrown = Bakery

Good Example:

Shape = FloristShape = LibraryShape = Bakery

Buildings must remain recognizable in grayscale.

Environmental Storytelling
==========================

Every building should imply:

*   Someone works here
    
*   Someone maintains it
    
*   Someone cares about it
    

Examples:

Library:Books left on table

Bakery:Fresh bread display

Florist:Watering can near entrance

Clockmaker:Gear parts on workbench

These details create life.

Final Art Direction Statement
=============================

Build the city like a collection of characters, not a collection of storefronts.

Use modular architecture as the foundation.

Use storytelling as the identity layer.

Every building should be recognizable by silhouette, memorable through its hero element, and unified through shared materials and world-building principles.

The city should feel handcrafted, warm, readable, scalable, and alive.
